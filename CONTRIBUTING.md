# Como contribuir

Obrigado por ajudar a tornar a integração com a BIBLIAAPI mais simples.

1. Abra uma issue descrevendo a linguagem, framework ou melhoria.
2. Mantenha cada exemplo pequeno, executável e sem dependências desnecessárias.
3. Leia tokens exclusivamente de variáveis de ambiente.
4. Inclua instruções de execução e tratamento básico de erros.
5. Nunca use uma chave real em testes ou documentação.

Ao enviar um pull request, confirme que o exemplo passa pela validação de sintaxe local.
